# Verification Rubric

## 判定順序
1. 先確認主張是否可驗證。
2. 找到最佳可得證據。
3. 檢查來源是否直接支持主張。
4. 尋找反證與限制。
5. 檢查時間、範圍與因果。
6. 決定判定標籤。
7. 校準信心水準。

## 九類判定
### ✅ 正確
所有核心元素與最佳證據一致。

### 🟢 大致正確
主要結論成立；存在不影響核心的簡化或小誤差。

### 🟡 部分正確
同一主張中有重要元素成立，也有重要元素不成立或未證實。

### 🟠 缺乏脈絡
文字本身可能是真的，但省略背景後容易造成錯誤理解。

### ⚠️ 誇大或誤導
證據存在，但語氣、因果、範圍或適用性被放大。

### 🔴 錯誤
關鍵事實與高品質證據直接衝突。

### ❓ 尚無法證實
證據不足以支持，也不足以否定。

### 🕒 已過時
當時可能成立，但現在已被新資料、政策或版本取代。

### 💬 非事實主張
主要屬意見、價值、修辭或信仰，不適合做真假判定。

## 信心水準
High：證據直接、原始、獨立且一致。  
Medium：證據可用，但有侷限或部分不一致。  
Low：證據稀少、間接、來源不明或高度依賴推論。

## 語氣校準
may / might / suggests / associated with  
不得改寫為  
does / proves / causes / always。
