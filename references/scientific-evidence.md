# Scientific Evidence Rules

## 1. 研究存在性
核對 title、authors、journal、year、DOI。

## 2. 方法
檢查：
- 研究設計
- 樣本數
- 對照組
- 隨機化／盲法（若適用）
- 測量方式
- 主要 outcome
- 統計分析

## 3. 外推限制
禁止自動把：
- 體外實驗 → 人體療效
- 動物實驗 → 人體療效
- 單一研究 → 科學共識
- 相關性 → 因果
- 模型結果 → 現實機制已證實
- 小樣本 → 普遍人口
- 單一地區 → 全世界

## 4. 系統性證據
高風險議題優先：
1. 指南／官方共識
2. 系統性回顧／Meta-analysis
3. 高品質原始研究
4. 其他研究

## 5. 統計
檢查：
- effect size
- confidence interval
- p-value（若有）
- absolute vs relative risk
- denominator
- multiple comparisons
- missing data

## 6. 科學用語
「顯示」、「提示」、「支持」通常不可自行升級為「證明」。
