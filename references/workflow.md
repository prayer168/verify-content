# Verification Workflow

1. Identify content type.
2. Extract atomic claims.
3. Tag claim types.
4. Prioritize high-impact claims.
5. Search primary / official sources.
6. Backfill with authoritative secondary sources.
7. Check source independence.
8. Match each claim to direct supporting evidence.
9. Search counter-evidence and limitations.
10. Normalize date/time.
11. Validate numbers and units.
12. Check correlation vs causation.
13. Check extrapolation.
14. Assign verdict.
15. Assign confidence.
16. Run self-validation loop.
17. Produce concise conclusion + detailed table.
18. If useful, rewrite into safe-to-share wording.
